# Models

`u2netp.onnx`: U²-Net-p salient object detection, used by
`src/stickers/cutout.js` to remove photo backgrounds in the browser.

- Model: U²-Net by Xuebin Qin et al., https://github.com/xuebinqin/U-2-Net
